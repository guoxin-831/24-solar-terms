# 字段说明

## 基础资料：`data/solar_terms.json`

文件为按交节顺序排列的 24 条记录。多项内容在字段中以全角分号 `；` 分隔。

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `name` | 节气名称 | `立春` |
| `term_rule` | 太阳黄经及公历常见日期范围 | `太阳黄经 315°；公历 2 月 3—5 日` |
| `climate` | 节气气候概述 | 气温、降水等描述 |
| `phenology` | 三候 | `一候东风解冻；二候蛰虫始振；三候鱼陟负冰` |
| `custom` | 相关习俗 | `迎春（演春）；鞭春牛（打春）` |
| `food` | 相关食俗 | `咬春：春盘、春饼、春卷、萝卜` |
| `poem` | 相关诗词及引用句 | `张栻《立春偶成》：律回岁晚冰霜少……` |
| `region` | 关联地域 | `浙江衢州九华立春祭` |
| `sources` | 资料名称与链接 | 中国非物质文化遗产网文章链接 |

`poem` 中的“未收录”表示该条记录没有诗词内容。`term_rule` 提供常见日期范围与太阳黄经，具体年份的交节时刻不包含在本数据中。

## 知识关系：`kg/relations.json`

| 字段 | 含义 |
| --- | --- |
| `schema_version` | 关系数据结构版本 |
| `source_dataset` | 基础资料路径 |
| `source_sha256` | 基础资料文件摘要 |
| `nodes` | 实体数组 |
| `relations` | 关系数组 |

节点字段：`id` 为节点 ID，`type` 为节点类型，`name` 为节点名称。节气节点另有 `season`；诗词节点另有 `quote`。

关系字段：`id` 为关系 ID；`from`、`to` 指向节点 ID；`type` 为关系类型；`source_record`、`source_field`、`source_value` 指向基础资料；`source_url` 为节气资料页；`source_scope` 的值为 `solar_term_record`。`order` 用于物候顺序，`display_text` 用于源字段的完整展示文字，`relation_note` 用于诗词引用说明。

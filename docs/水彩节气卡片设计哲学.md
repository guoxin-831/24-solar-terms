# 水色廿四

## 设计哲学

**一、纸是主角。**
一切颜色都必须先服从纸。宣纸不是背景板，而是承载时间的容器：它有纤维的走向、有微微的暖黄、有被水浸过之后仍不肯消失的韧性。每一张卡片的第一笔不是画，而是留白——留出纸的呼吸，让墨色有地方沉淀。制裁纸、调色、落笔，每一步都要像老匠人对待一张好纸那样，不急，不省。

**二、颜色是水，不是漆。**
水彩的全部尊严在于"化开"。颜色不应有边界：一层颜色在另一层湿的时候渗透进去，边缘晕出深浅不一的毛边，中间偶尔留下水痕与沉淀。因此画面由多层半透明的径向晕染叠加而成，正片叠底，让纸的纹理从颜色下面透出来。凡是干净的、等宽的、可被计算出来的色块，一律视为失败。

**三、一季一调，一帧一相。**
四季各有主色与辅色：春取青绿与桃粉，夏取湖蓝与竹青，秋取赭石与枫红，冬取黛青与霜白。但同一季里的每一帧都不许完全相同——晕染的位置、浓淡、笔锋的角度都要有手绘的偏移，像同一位画师在同一天里画了六张，而不是复制了六次。这种微小的不齐整，正是人手的证据。

**四、墨是骨。**
水色柔软，必须有墨来立骨。一笔干笔横扫，淡墨、细、略斜，像远山的一道脊，也像枝梢的一挑。它只出现一次，克制到几乎没有，却让整张画面站得住。朱红的印记是唯一的强音：方寸之间，一枚小印，把整幅画从"图"变成"证"。

**五、字要退，也要在。**
文字是题款，不是说明。节气名以宋体大字落在纸色最厚的地方，字距拉开，像写在画上的款识；物候与日期缩小、变淡，藏在下方。字号、粗细、灰度的层级必须精确到一眼能读完、又不抢画面。任何一行字都不许压到画的呼吸处，也不许有半个字被裁掉。

**六、手感即水准。**
最终的卡片应当看起来像是有人花了整夜调那几层水色、试了十几次笔锋角度才定下来的。边缘的毛、颜色的沉、印泥的厚、纸纹的细，都要经得起放大看。不是"做了二十四张卡片"，而是"画了二十四帧小画"——这是唯一可以被接受的标准。
